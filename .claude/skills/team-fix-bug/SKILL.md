# team-fix-bug

不具合: $ARGUMENTS
1. 共通ルールと案件情報、差分、ログ、再現手順を確認する。秘密値を表示しない。
2. 期待する振る舞いを仕様から確認する。再現しなければ環境差を調査し、未再現と報告する。原因を断定しない。
3. 原因仮説を証拠で絞り、再現する最小の回帰テストを追加する。修正前の失敗を実行して確認する。
4. 原因へ最小修正を行い、同テストの成功と関連の回帰テストを確認する。無関係なリファクタリングを混ぜない。
5. python3 scripts/checks.py app と、必要な実動作確認を行う。未設定ならBLOCKED。
出力: 症状 / 原因と根拠 / 修正範囲 / 修正前後の結果 / 回帰範囲 / 未検証・残存リスク。
