# team-implement

対象タスク: $ARGUMENTS
1. CLAUDE.md、docs/PROJECT.md、指定タスクを読み、受入条件と変更境界を確認する。
2. 差分を確認し他者変更を守る。project-checks.jsonと既存の検証手順を確認する。未設定はBLOCKEDとし、検証設定案を示す。
3. 既存コードを調査し、軽微な実装判断は既存規約で進める。重大な仕様判断は実装前に確認する。
4. 小さな振る舞い単位で、テスト失敗→最小実装→成功→整理を繰り返す。失敗が実装不足によるものか確認する。
5. python3 scripts/checks.py app を実行する。受入条件に応じアプリを起動し実動作を確認する。実行不能は理由と未検証範囲を示す。
6. 差分を再確認し、無関係な変更・秘密値・過剰な抽象化を除く。必要な文書を更新する。
出力: 変更概要 / 条件ごとの結果と証跡 / 検証コマンドと結果 / 未検証 / リスク / 承認待ち。
push、PR作成、merge、配備は個別に依頼されていない限り行わない。
