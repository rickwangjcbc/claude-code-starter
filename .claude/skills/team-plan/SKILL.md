# team-plan

対象: $ARGUMENTS
1. CLAUDE.mdとdocs/PROJECT.mdを読み、対象コードと既存仕様を調査する。今回はコード変更しない。
2. 目的、対象外、利用者、正常系・異常系・境界条件を整理する。
3. 調査で判明した事実と、未確認事項を分ける。質問は仕様・セキュリティ・費用・互換性等の重要事項へ絞り、推奨案を添える。
4. 変更対象、段階的な実装方針、テスト、実動作確認、移行・復旧を示す。
5. 結果をtemplates/TASK.mdの形式で提示する。ファイル保存が依頼範囲にあれば新規タスク文書として保存する。既存タスクは無断上書きしない。
出力: 要件案 / 受入条件 / 方針 / リスク / 確認事項。未承認案を確定仕様にしない。
