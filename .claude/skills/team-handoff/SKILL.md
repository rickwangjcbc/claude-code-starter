# team-handoff

引継ぎ対象: $ARGUMENTS
1. 共通ルールと案件情報、作業差分と検証記録を確認する。編集は依頼範囲のみ。
2. 次を根拠付きでまとめる: 目的 / 入力commit / 出力commitまたは未commit / 標準版 / 変更ファイル / 受入条件ごとの状態 / 実行検証と結果 / 未決事項 / 次の作業 / 人の承認者。
3. commitや承認者が未設定なら未設定と記載し、統合可能と扱わない。秘密値、全会話、内部思考は引継ぎ票へ含めない。
4. 実行済み・未実行・BLOCKEDを明確に分ける。次担当への範囲外の作業指示を勝手に追加しない。
出力: 上記の引継ぎ票。ファイル保存は依頼がある場合に既存を保護して行う。
