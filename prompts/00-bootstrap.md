# 最初にClaude Codeへ渡す依頼文（そのまま貼付可）

このリポジトリへ同梱したClaude Code開発標準を導入してください。
最初にREADME.md、CLAUDE.md、docs/SETUP.md、docs/PROJECT.mdを読んでください。
既存ファイルや他者の未コミット差分は上書き・破棄しないでください。
今回は標準の導入だけで、アプリ機能の実装・リモート公開・push・配備は行わないでください。

1. ソース、依存lock、既存CI、テスト、起動手順を調査し、確認できた案件情報をdocs/PROJECT.mdへ記載してください。
2. 既存の実テスト・lint・型検査・ビルドなどから必要な検証を選び、project-checks.jsonへ実行引数配列で設定してください。架空のコマンドや常に成功する代替を使わないでください。
3. CIへ必要なランタイム設定とlockに基づく依存導入を追加してください。既存CIは無断で置き換えないでください。
4. 雛形検査・回帰試験・案件検査を実行し、結果を分けて報告してください。環境不足はBLOCKEDです。
5. 人の承認者、業務要件、アクセス権など調査できない重要項目だけを、推奨案とともに確認してください。
6. Claude Codeの採用版でルール・Skills・権限設定の読込確認と、無害なfixtureによる許可/拒否確認を行ってください。実秘密ファイルを試験に使わないでください。
7. 導入済み、未設定、未検証、承認待ちを明記してください。未設定のまま適用済みとしないでください。
